### Workout Logger

A modern workout logging application with a breathtaking UI.

📁 Location: `workout-app/`

**Features:**
- Beautiful dark blue gradient UI with #13B8B1 accent color
- Floating action button for quick workout creation
- Templates and History management
- Glassmorphism effects and smooth animations
- Responsive mobile-first design
