# Workout Logger

A modern, breathtaking workout logging application built with React and Vite.

![Workout Logger Landing Page](https://github.com/user-attachments/assets/d5675c68-27de-4467-85e7-7f39b08eb5e0)

## Features

- **Beautiful Dark UI**: Stunning dark blue gradient background with modern design
- **Accent Color**: #13B8B1 teal accent for buttons and interactive elements
- **Floating Action Button**: Quick access to add new workouts
- **Templates**: Create and manage workout templates for efficient logging
- **History**: Track and review your workout history
- **Glassmorphism Effects**: Modern blur and transparency effects
- **Smooth Animations**: Polished hover and transition effects
- **Responsive Design**: Mobile-first approach that works on all devices

## Getting Started

### Prerequisites

- Node.js (version 18 or higher)
- npm or yarn

### Installation

1. Navigate to the workout-app directory:
```bash
cd workout-app
```

2. Install dependencies:
```bash
npm install
```

3. Start the development server:
```bash
npm run dev
```

4. Open your browser and visit `http://localhost:5173`

## Available Scripts

- `npm run dev` - Start development server
- `npm run build` - Build for production
- `npm run preview` - Preview production build
- `npm run lint` - Run ESLint
